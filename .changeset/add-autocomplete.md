Add Autocomplete to `owsem-ui/base`: a text input with suggestions, Base UI's `Autocomplete.Root`
(with its `mode`: `list`, `both`, `inline`, `none`), `Value`, `Input`, `InputGroup`, `Trigger`, `Icon`,
`Clear`, `Portal`, `Backdrop`, `Positioner`, `Popup`, `Arrow`, `List`, `Row`, `Item`, `Group`,
`GroupLabel`, `Collection`, `Separator`, `Status`, `Empty`, and the filter helpers. It shares
Combobox's field, popup, and list, so the two look alike, and takes `size="sm|md|lg"`. Both flavors,
CSS and Tailwind.
