Add Checkbox Group, from `owsem-ui/base`. `CheckboxGroup` is Base UI's group laid out as Radio Group
is: `<label>` rows with Button's geometry and Glide's highlight, and `size` (`sm`, `md`, `lg`) that
reaches the Checkboxes in it by context. A `Checkbox` in a group takes the group's size unless it has
its own. A parent box (`<Checkbox.Root parent />` with `allValues`) shows the minus while some are
ticked. Both flavors, CSS and Tailwind.
