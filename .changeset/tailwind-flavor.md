Add a Tailwind CSS v4 flavor of Button, Separator, Kbd, Toggle, Input, Field, Fieldset, Form,
Switch, Checkbox, Icon Morph, Tooltip, Copy Button, Popover, Dialog, Scroll Area, Table, Radio
Group, Toggle Group, Tabs, Menu, Select, Toolbar, Code Block, Command Menu, Color Picker, and Table
of Contents: the same `<name>.tsx`, with the styles as utility classes in `<name>-variants.ts`.
Glide, the hover highlight they share, comes along in `lib/glide/`. Copy them from the docs' Manual
install. `owsem-ui/tailwind.css` also carries the keyframes, variants, and registered properties
they use.
