## Instalasi [#installation]

<Install />

Impor dari `owsem-ui/base`. Di registry, itemnya `popover`; tombol pada contoh juga butuh `button`
dan `toggle`.

## Penggunaan [#usage]

```tsx
import { Button, Popover } from "owsem-ui/base";

export function SharePopover() {
  return (
    <Popover.Root>
      <Popover.Trigger render={<Button variant="outline" />}>Bagikan</Popover.Trigger>
      <Popover.Portal>
        <Popover.Positioner>
          <Popover.Popup>
            <Popover.Arrow />
            <Popover.Title>Bagikan draf</Popover.Title>
            <Popover.Description>Siapa pun yang punya link bisa membacanya.</Popover.Description>
          </Popover.Popup>
        </Popover.Positioner>
      </Popover.Portal>
    </Popover.Root>
  );
}
```

Popover membuka panel kecil dari sebuah tombol: judul, satu-dua baris, dan kontrol, pada material
raised dengan bayangan popup, dengan panah opsional ke arah tombol. Berbeda dari tooltip, ia memuat isi
yang dibaca dan ditindaklanjuti orang, dan bekerja sama baik dengan sentuhan maupun pembaca layar. Base
UI menempatkannya dan menangani fokus: masuk ke panel saat terbuka, kembali ke tombol saat menutup.

## Anatomi [#anatomy]

<InspectButton />

Base UI merender bagian, penamaan dialog, dan fokus. OwsemUI menata panel, panah, judul, dan
deskripsi, mengatur offset 10px, dan membawa arah teks ke portal. Root, Portal, dan Backdrop tidak
menambah tampilan sendiri. Root tidak merender elemen, jadi di Inspect ia adalah kotak yang memuat
trigger dan panelnya.

| Bagian | Elemen | Catatan |
| --- | --- | --- |
| <Part name="Root" /> | tidak ada | Hanya state: `open`, `modal`, dan `handle` |
| <Part name="Trigger" /> | Tombol Anda | Diteruskan ke `render`; `aria-expanded`, dan `data-popup-open` saat terbuka |
| Portal | `div` | Memindahkan panel ke akhir body, atau ke `container` |
| Positioner | `div.ow-popover__positioner` | `side`, `align`, `sideOffset` (10), `arrowPadding` (12), dan `dir`; berjangkar pada kotak diam trigger |
| <Part name="Popup" /> | `div.ow-popover__popup` | `role="dialog"`, `data-side`, dan `data-instant` saat melewati animasi |
| <Part name="Arrow" /> | `div.ow-popover__arrow` | Opsional dan `aria-hidden`, dengan `data-side`; persegi yang diputar, setengahnya terlihat |
| <Part name="Title" /> | `h2.ow-popover__title` | Menamai dialog |
| <Part name="Description" /> | `p.ow-popover__description` | Mendeskripsikan dialog, muted |
| <Part name="Close" /> | Tombol Anda | Menutup popover |

## Referensi API [#api]

<BaseUiReference />

### Popover.Positioner

#### Props

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `sideOffset` | `number \| function` | `10` | Jarak ke trigger, dengan ruang untuk panah. Default Base UI adalah `0` |
| `arrowPadding` | `number` | `12` | Menjaga panah dari sudut membulat. Default Base UI adalah `5` |

`Popover.Trigger` bisa diletakkan di mana saja, di luar Root-nya, dihubungkan lewat handle: setiap trigger dengan handle itu membuka panel yang sama di bawahnya, dan handle membuka serta menutupnya dari kode. Dengan `modal={true}`, gulir halaman ditahan lewat kunci milik OwsemUI, yang membiarkan `overflow` halaman; saat dibuka dengan hover atau sentuhan, aturan Base UI berlaku.

### Kelas CSS

| Kelas CSS | Bagian |
| --- | --- |
| `ow-popover__positioner` | Positioner |
| `ow-popover__popup` | Popup |
| `ow-popover__arrow` | Arrow |
| `ow-popover__title` | Title |
| `ow-popover__description` | Description |

## Aksesibilitas [#accessibility]

| Tombol | Aksi |
| --- | --- |
| Enter, Spasi | Pada trigger: membuka panel; fokus pindah ke dalamnya |
| Tab | Berpindah antar kontrol panel |
| Escape | Menutup panel; fokus kembali ke trigger |

- Pembaca layar mengumumkan dialog bernama judulnya dan berdeskripsi deskripsinya.
- `modal` bernilai false secara default, jadi halaman tetap bisa dipakai selama panel terbuka; `true`
  atau `"trap-focus"` menjaga fokus di dalam. Dengan `true`, gulir halaman ditahan tanpa style `overflow`.
- `initialFocus` dan `finalFocus` memilih ke mana fokus pergi.
- Dengan `prefers-contrast: more`, panel mendapat cincin 1px dalam `--ow-edge`. Pada forced colors panel
  tetap bertepi 1px dalam warna sistem, begitu juga panahnya.

## Tema [#theming]

Popover membaca token tema ini. Setel pada Popup dengan sebuah kelas, atau pada `:root` untuk semua
popover. Kelas di sekitar trigger tidak menjangkaunya: panel dirender dalam portal, di luar subpohon
trigger.

<Tokens />

| Token tema | Fungsi |
| --- | --- |
| `--ow-raised-bg` | Permukaan, termasuk panahnya |
| `--ow-popup-shadow` | Bayangan, termasuk panahnya |
| `--ow-edge` | Cincin pada `prefers-contrast: more` |
| `--ow-fg` | Teks |
| `--ow-muted` | Deskripsi |
| `--ow-radius` | Sudut |

<ForMode mode="isolated">

Pada mode isolated, nilainya ada di tiap Popup, jadi setel pada Popup dengan sebuah kelas.

</ForMode>

Panel punya padding 16px; kelas pada Popup mengubahnya, dan mengatur lebarnya, seperti `share.css`
pada contoh.

## Gerak [#motion]

Panel tumbuh dari tombolnya dalam 180 ms, dari 0,96 dan transparan, dari ujung panah, dan keluar dalam
120 ms. Saat dibuka dari keyboard, atau ditutup dengan Escape, ia melewati animasi. Panel mengukur dari
kotak diam tombol, jadi tombol yang masih memantul dari tekanannya tidak menggesernya. Dengan
`prefers-reduced-motion`, panel memudar tanpa tumbuh.
