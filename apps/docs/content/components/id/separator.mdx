## Instalasi [#installation]

<Install />

Impor dari `owsem-ui/base`. Untuk menyalin kode sumbernya ke project Anda, pakai item `separator`
dari registry.

## Penggunaan [#usage]

```tsx
import { Separator } from "owsem-ui/base";

export function Settings() {
  return (
    <section>
      <h3>Profil</h3>
      <Separator />
      <h3>Keamanan</h3>
    </section>
  );
}
```

Separator memisahkan konten dengan garis tipis: satu garis 1px dalam warna garis, cukup tenang untuk
membiarkan konten di depan. `orientation` adalah `horizontal` (bawaan) atau `vertical`. Separator
vertikal mengisi tinggi baris di dalam container flex atau grid, dan tetap setebal 1px meski
container merentangkannya.

## Aksesibilitas [#accessibility]

Separator tidak dapat difokus dan tidak punya interaksi keyboard.

- Screen reader mengumumkannya sebagai separator lewat `role="separator"` dan `aria-orientation`.
- Pada forced colors, garis memakai warna sistem sehingga tetap terlihat.

## Tema [#theming]

Separator membaca satu token tema. Setel pada Separator, atau pada elemen di sekitarnya.

<Tokens />

| --- | --- |

<ForMode mode="isolated">

</ForMode>

## Gerak [#motion]

Separator tidak bergerak: ia tidak punya state maupun transisi, jadi `prefers-reduced-motion` tidak
mengubah apa pun.
