Separator divides content with an etched line: a 1 px dark line with a 1 px light line beside it,
as if cut into the surface with light from above. Scroll to start the tour; the stage follows each
part.

## Anatomy [#anatomy]

A single part. Base UI renders `<div role="separator">` with `aria-orientation` and
`data-orientation`; OwsemUI adds the `ow-separator` class and draws both lines as borders. Inspect
(I) outlines it on the stage, with its tokens.

| Part | Element | Tokens |
| --- | --- | --- |
| <Part name="Root" /> | `div.ow-separator` | `--ow-line-dark`, `--ow-line-light` |

## States and variants [#states]

`orientation` is `horizontal` (default) or `vertical`; the stage now shows the vertical one. A
vertical separator fills the row height inside a flex or grid container, and stays 2 px thick even
when the container stretches it.

## Keyboard and accessibility [#keyboard]

Separator is not focusable and has no keyboard interaction. Screen readers announce it as a
separator through `role="separator"` and `aria-orientation`. In forced colors (Windows High
Contrast), both lines use the system color so the line stays visible.

## Customization [#customization]

The stage controls are open; once you change a color, its CSS is in the `settings.css` tab.

Separator reads these theme tokens. Set one on an element to change the separators inside it.

| Theme token | Purpose |
| --- | --- |
| `--ow-line-dark` | Dark line |
| `--ow-line-light` | Light line beside it |

## Ship it [#ship]

The code drawer writes the component exactly as the stage is set up. Change anything and the lines
that moved light up.

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className` | `string \| (state) => string` | |
| `style` | `CSSProperties` | |
| `render` | `ReactElement \| (props, state) => ReactElement` | |

The ref goes to the `div`, and other props pass through to Base UI as they are.
