title: Separator

import { Separator } from "owsem-ui/base";

## Overview

Separator divides content with an etched line: a 1 px dark line with a 1 px light line beside it,
as if cut into the surface with light from above.

<div className="lab-demo">
  <p>Profile</p>
  <Separator />
  <p>Security</p>
</div>

## Anatomy

A single part. Base UI renders `<div role="separator">` with `aria-orientation` and
`data-orientation`; OwsemUI adds the `ow-separator` class and draws both lines as borders.

## States and variants

`orientation` is `horizontal` (default) or `vertical`. A vertical separator fills the row height
inside a flex or grid container, and stays 2 px thick even when the container stretches it.

<div className="lab-demo">
  <div className="lab-demo-row">
    <span>Draft</span>
    <Separator orientation="vertical" />
    <span>Published</span>
    <Separator orientation="vertical" />
    <span>Archived</span>
  </div>
</div>

## Keyboard and accessibility

Separator is not focusable and has no keyboard interaction. Screen readers announce it as a
separator through `role="separator"`. In forced colors (Windows High Contrast), both lines use the
system color so the line stays visible.

## Ship it

```sh
pnpm add owsem-ui
```

```tsx
import "owsem-ui/styles.css";
import { Separator } from "owsem-ui/base";

export function Sections() {
  return (
    <>
      <p>Profile</p>
      <Separator />
      <p>Security</p>
    </>
  );
}
```

| Component token | Default | Purpose |
| --- | --- | --- |
| `--ow-separator-line-dark` | `--ow-line-dark` | Dark line |
| `--ow-separator-line-light` | `--ow-line-light` | Light line beside it |

Component tokens override the theme tokens for separators inside that element only:

```css
.sidebar {
  --ow-separator-line-dark: #c8c8d0;
}
```
