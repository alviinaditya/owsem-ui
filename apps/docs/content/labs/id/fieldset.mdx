Fieldset mengelompokkan field yang berkaitan di bawah satu legend, dan satu `disabled` sampai ke
semuanya. Base UI menamai grupnya dan meneruskan state-nya; OwsemUI menambahkan jarak yang rata dan garis
terukir di bawah legend. Gulir untuk mulai tur; stage mengikuti setiap bagian.

```tsx
<Fieldset.Root>
  <Fieldset.Legend>Penagihan</Fieldset.Legend>
  <Field.Root>
    <Field.Label>Jalan</Field.Label>
    <Field.Control />
  </Field.Root>
</Fieldset.Root>
```

## Satu sakelar, satu jarak [#group]

`disabled` di root sampai ke setiap kontrol di dalamnya, apa pun itu: Base UI meneruskannya ke Field-nya,
dan `<fieldset>` native menonaktifkan sisanya. Screen reader mendengar legend sebagai nama grup saat fokus
masuk ke dalamnya.

Stage memutarnya: pointer menekan Sama dengan alamat kirim, seluruh alamat memudar, lalu kembali.

Semua yang ada di grup berjarak sama, di bawah legend dan antar-field: `1.25em`, 17,5px pada ukuran 14px.
Keterangannya membaca jarak yang dipakai, dan panel Kontrol mengubahnya dengan CSS biasa.

## Anatomi [#anatomy]

Dua bagian. Inspeksi (I) menandainya di stage.

| Bagian | Elemen | Catatan |
| --- | --- | --- |
| <Part name="Root" /> | `fieldset.ow-fieldset` | Satu kolom tanpa bingkai; `disabled`, dan `data-disabled` selama disabled |
| <Part name="Legend" /> | `div.ow-fieldset__legend` | Menamai grup lewat `aria-labelledby`; `data-disabled`. Garis terukirnya adalah `::after` miliknya |

## State dan varian [#states]

Stage menampilkan tema terang dan gelap berdampingan.

| State | Tandanya |
| --- | --- |
| Aktif | Legend `--ow-fg`, di atas garis |
| Disabled | Legend dengan opacity 45%, dan setiap kontrol memudar dengan tampilan disabled-nya sendiri |

## Keyboard dan aksesibilitas [#keyboard]

Fieldset tidak menerima fokus: Tab melewati kontrol-kontrolnya, dan melompati semuanya selama disabled. Ini
`<fieldset>` native, jadi perannya `group`, dinamai oleh legend. Beri legend pada setiap grup, dan pakai
`render` untuk heading bila kerangka halaman membutuhkannya.

Tidak ada yang bergerak, jadi reduced motion tidak mengubah apa pun. Di mode forced colors (Windows High
Contrast), garisnya tetap ada, karena berupa dua border. Dari kanan ke kiri, legend berada di kanan.

## Kustomisasi [#customization]

Stage menampilkan tiga cara mengubahnya. Kontrolnya terbuka: pilih warna garis atau jaraknya, dan kodenya
mengikuti.

**Token** yang dipasang di legend, di root, atau di elemen apa pun di sekitarnya mengubah grup di dalamnya.

```css
.billing {
  --ow-line-dark: #a07a1c;
}
```

| Token tema | Fungsi |
| --- | --- |
| `--ow-fg` | Legend |
| `--ow-line-dark` | Sisi gelap garis |
| `--ow-line-light` | Sisi terang garis |

**`className`** mengalahkan nilainya sendiri, tanpa `!important`. `gap` adalah satu properti di satu class,
dan garisnya adalah `::after` milik legend, jadi satu aturan menghapusnya. Di sini, field-nya duduk dalam dua
kolom:

```css
.billing {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 0.75em;
}

.billing > .ow-fieldset__legend {
  grid-column: 1 / -1;
}

.plain::after {
  content: none;
}
```

Ia tidak punya margin luar dan mengisi induknya, jadi Form atau layout Anda sendiri yang mengatur jarak di
sekitarnya.

**Komposisi:** `render` menukar elemen mana pun. Legend bisa menjadi heading, dan tetap menamai grupnya.

```tsx
<Fieldset.Legend render={<h3 />}>Alamat penagihan</Fieldset.Legend>
```

## Ship it [#ship]

Drawer kode menulis komponen persis seperti yang diatur di stage.

| Bagian | Prop | Tipe | Bawaan |
| --- | --- | --- | --- |
| `Root` | `disabled` | `boolean` | `false` |

Kedua bagian menerima `className`, `style`, `render`, dan `ref`, dan props lain diteruskan ke Base UI apa
adanya. Ref root diteruskan ke `fieldset`, dan ref legend ke `div`-nya.

Impor dari `owsem-ui/base`. Di registry, namanya item `fieldset`. Ia tidak butuh komponen lain: Field adalah
yang biasanya diisikan, dan kontrol apa pun bisa.
