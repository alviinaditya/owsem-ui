Popover membuka panel kecil dari sebuah tombol: judul, satu atau dua baris teks, dan kontrol, di
atas material panel dengan bayangan popup, dengan panah opsional ke arah tombol. Base UI yang
menaruhnya dan mengatur fokus. Gulir untuk mulai tur; stage mengikuti setiap bagian.

## Panel dari trigger-nya [#panel]

Panel tumbuh dari tombolnya dalam 180 ms, dari 0,96 dan transparan, dengan ease-out, dari ujung
panah; panel pergi dalam 120 ms. Bila dibuka dari keyboard, panel langsung muncul. Fokus masuk ke
panel dan kembali ke tombol saat panel tertutup: dengan Escape, klik di luar, atau
`Popover.Close`.

Berbeda dengan tooltip, popover untuk konten yang dibaca dan dipakai, dan bekerja sama baiknya di
layar sentuh dan screen reader. Panelnya adalah `dialog` yang dinamai oleh `Popover.Title` dan
dideskripsikan oleh `Popover.Description`.

Stage memutarnya: pointer membuka Bagikan, menyalakan dan mematikan komentar di dalam panel, lalu
menutupnya dari tombol. Putar scene memutarnya lagi.

## Ditaruh dan menunjuk [#placement]

Base UI menaruh panel di `side` yang diminta, bawaannya `bottom`, 10px dari tombolnya, dan
membaliknya ke sisi seberang bila panel akan keluar layar. Panah berada di tepi panel dengan
permukaan dan bayangan yang sama, jadi tepinya adalah tepi panel (di tema gelap, garis terang di
dalam cincin gelap) dan terbuka ke dalamnya. Panah menunjuk tengah tombol meski panel bergeser
agar tetap di layar, dan menjauh dari sudut yang membulat.

Panel disematkan terbuka di stage: pilih sisi atau matikan panah di kontrol.

## Satu panel, banyak trigger [#detached]

`Popover.Trigger` bisa berada di mana saja, di luar `Popover.Root`-nya, dihubungkan oleh handle
dari `Popover.createHandle()`. Setiap trigger dengan handle itu membuka panel yang sama, di
bawah dirinya; handle juga bisa membuka dan menutupnya dari kode. Docs ini bekerja dengan cara
itu: tombol Token di stage, menu Lainnya, dan setiap link Ubah membuka satu panel Pengaturan token.

Stage memutarnya: Bagikan membuka panel, link di bawah toolbar mengambil alih, lalu menutupnya.

## Anatomi [#anatomy]

Base UI merender bagian-bagiannya, penamaan dialog, dan fokus; OwsemUI memberi gaya pada panel,
panah, judul, dan deskripsi, memasang jarak 10px, dan membawa arah teks ke dalam portal. Root,
Portal, Close, dan Backdrop tidak menambah tampilan. Inspeksi (I) menandai bagian lainnya di stage;
pilih sebuah nama, di sini atau di stage, untuk melihat tokennya.

| Bagian | Elemen | Catatan |
| --- | --- | --- |
| <Part name="Trigger" /> | Tombol Anda | Diberikan lewat `render`; `aria-expanded`, dan `data-popup-open` selama terbuka |
| Positioner | `div.ow-popover__positioner` | `side`, `align`, `sideOffset` (10), `arrowPadding` (12), dan `dir` |
| <Part name="Popup" /> | `div.ow-popover__popup` | `role="dialog"`, `data-side`, dan `data-instant` saat melewati animasi |
| <Part name="Arrow" /> | `div.ow-popover__arrow` | Opsional dan `aria-hidden`, dengan `data-side`; persegi yang diputar, separuhnya tampil |
| <Part name="Title" /> | `h2.ow-popover__title` | Menamai dialog |
| <Part name="Description" /> | `p.ow-popover__description` | Mendeskripsikan dialog, muted |
| Close | Tombol Anda | Menutup popover |

## State dan varian [#states]

Stage menampilkan panel di kedua tema, dengan dan tanpa panah. Permukaannya material panel di
keduanya, dengan bayangan popup, dan panah memakai permukaan serta tepi yang sama.

| State | Tandanya |
| --- | --- |
| Masuk | Dari 0,96 dan transparan ke ukuran penuh, dalam 180 ms, dengan ease-out |
| Terbuka | `data-open`, `data-side` di popup dan panah; `data-popup-open` di trigger |
| Langsung | `data-instant`: `click` dari keyboard, `dismiss` setelah Escape, `trigger-change` antar trigger |
| Keluar | Kembali ke 0,96 dan transparan, dalam 120 ms |

## Keyboard dan aksesibilitas [#keyboard]

| Tombol | Aksi |
| --- | --- |
| Enter, Space | Di trigger: membuka panel; fokus masuk ke dalamnya |
| Tab | Berpindah antar kontrol di panel |
| Escape | Menutup panel; fokus kembali ke trigger |

Screen reader mengumumkan dialog yang dinamai oleh judul dan dideskripsikan oleh deskripsinya.
`modal` bawaannya false, jadi halaman tetap bisa dipakai selama panel terbuka; pasang `true` atau
`"trap-focus"` untuk menahan fokus di dalam. `initialFocus` dan `finalFocus` menentukan ke mana
fokus pergi.

Dengan `prefers-reduced-motion`, panel memudar tanpa tumbuh. Di forced colors (Windows High
Contrast), panel tetap punya tepi 1px dengan warna sistem, begitu pula panahnya.

## Kustomisasi [#customization]

Kontrol stage terbuka: pilih sisi, panah, permukaan, atau warna teks, dan kodenya ikut berubah.

Popover membaca token tema berikut. Pasang di popup lewat class, seperti `share.css`, atau untuk
semua popover di `:root`. Class di sekitar trigger tidak sampai: panel dirender di portal, di luar
subtree trigger-nya.

| Token tema | Fungsi |
| --- | --- |
| `--ow-panel` | Permukaan, juga untuk panah |
| `--ow-popup-shadow` | Tepi dan bayangan, juga untuk panah |
| `--ow-fg` | Teks |
| `--ow-muted` | Deskripsi |
| `--ow-radius` | Sudut, ditambah 4px seperti menu |

## Ship it [#ship]

Drawer kode menulis popover persis seperti pengaturan stage. Ganti sisi, panah, atau warna, dan
baris yang berubah akan menyala.

| Bagian | Prop | Tipe | Bawaan |
| --- | --- | --- | --- |
| Root | `open`, `defaultOpen`, `onOpenChange` | | |
| Root | `modal` | `boolean \| "trap-focus"` | `false` |
| Root | `handle` | `Popover.Handle` | |
| Trigger | `handle`, `payload` | | |
| Trigger | `openOnHover`, `delay` | `boolean`, `number` | `false`, `300` |
| Positioner | `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| Positioner | `align` | `"start" \| "center" \| "end"` | `"center"` |
| Positioner | `sideOffset` | `number` | `10` |
| Positioner | `arrowPadding` | `number` | `12` |
| Popup | `initialFocus`, `finalFocus` | | |
| Semua bagian | `className`, `style`, `render` | | |

Nilai bawaan `sideOffset` dan `arrowPadding` berasal dari OwsemUI; sisanya dari Base UI, yang
mendokumentasikannya. Ref diteruskan ke elemen setiap bagian.

Impor dari `owsem-ui/base`. Di registry, item-nya `popover`; toolbar di sini juga butuh `toolbar`
dan `toggle`.
