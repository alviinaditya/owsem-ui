import { Separator } from "owsem-ui/base";

## Ikhtisar

Separator memisahkan bagian konten dengan garis terukir: garis gelap 1 px dengan garis terang 1 px
di sebelahnya, seolah ditoreh ke permukaan dengan cahaya dari atas.

<div className="lab-demo">
  <p>Profil</p>
  <Separator />
  <p>Keamanan</p>
</div>

## Anatomi

Satu bagian saja. Base UI merender `<div role="separator">` dengan `aria-orientation` dan
`data-orientation`; OwsemUI menambahkan class `ow-separator` dan kedua garisnya sebagai border.

## State dan varian

`orientation` bernilai `horizontal` (bawaan) atau `vertical`. Separator vertikal mengisi tinggi baris
di dalam container flex atau grid, dan ketebalannya tetap 2 px walaupun container meregangkannya.

<div className="lab-demo">
  <div className="lab-demo-row">
    <span>Draf</span>
    <Separator orientation="vertical" />
    <span>Terbit</span>
    <Separator orientation="vertical" />
    <span>Arsip</span>
  </div>
</div>

## Keyboard dan aksesibilitas

Separator tidak bisa difokus dan tidak punya interaksi keyboard. Screen reader mengenalinya sebagai
pemisah lewat `role="separator"`. Di mode forced colors (Windows High Contrast), kedua garis memakai
warna sistem sehingga tetap terlihat.

## Ship it

```sh
pnpm add owsem-ui
```

```tsx
import "owsem-ui/styles.css";
import { Separator } from "owsem-ui/base";

export function Sections() {
  return (
    <>
      <p>Profil</p>
      <Separator />
      <p>Keamanan</p>
    </>
  );
}
```

| Token komponen | Bawaan | Fungsi |
| --- | --- | --- |
| `--ow-separator-line-dark` | `--ow-line-dark` | Garis gelap |
| `--ow-separator-line-light` | `--ow-line-light` | Garis terang di sebelahnya |

Token komponen menimpa token tema hanya untuk Separator di dalam elemen itu:

```css
.sidebar {
  --ow-separator-line-dark: #c8c8d0;
}
```
