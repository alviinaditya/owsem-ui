## Pemakaian

```sh
pnpm add owsem-ui
```

```tsx
import "owsem-ui/styles.css";
import { Separator } from "owsem-ui/base";

export function Sections() {
  return (
    <>
      <p>Profil</p>
      <Separator />
      <p>Keamanan</p>
    </>
  );
}
```

Separator vertikal mengisi tinggi baris di dalam container flex atau grid.

## Tampilan

Separator memakai material garis terukir: garis gelap 1 px dengan garis terang 1 px di sebelahnya,
seolah ditoreh ke permukaan dengan cahaya dari atas. Di mode forced colors (Windows High Contrast),
keduanya memakai warna sistem sehingga garis tetap terlihat.

## Aksesibilitas

Base UI merender `<div role="separator">` dengan `aria-orientation`, sehingga screen reader
mengenalinya sebagai pemisah. Separator tidak bisa difokus.

## Token

| Token komponen | Bawaan | Fungsi |
| --- | --- | --- |
| `--ow-separator-line-dark` | `--ow-line-dark` | Garis gelap |
| `--ow-separator-line-light` | `--ow-line-light` | Garis terang di sebelahnya |

Token komponen menimpa token tema hanya untuk Separator di dalam elemen itu:

```css
.sidebar {
  --ow-separator-line-dark: #c8c8d0;
}
```
