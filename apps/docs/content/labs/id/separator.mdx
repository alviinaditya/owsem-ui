Separator memisahkan bagian konten dengan garis terukir: garis gelap 1 px dengan garis terang 1 px
di sebelahnya, seolah ditoreh ke permukaan dengan cahaya dari atas. Gulir untuk mulai tur; stage
mengikuti setiap bagian.

## Anatomi [#anatomy]

Satu bagian saja. Base UI merender `<div role="separator">` dengan `aria-orientation` dan
`data-orientation`; OwsemUI menambahkan class `ow-separator` dan menggambar kedua garis sebagai
border. Inspeksi (I) menandainya di stage, beserta tokennya.

| Bagian | Elemen | Token |
| --- | --- | --- |
| <Part name="Root" /> | `div.ow-separator` | `--ow-line-dark`, `--ow-line-light` |

## State dan varian [#states]

`orientation` bernilai `horizontal` (bawaan) atau `vertical`; stage sekarang menampilkan yang
vertikal. Separator vertikal mengisi tinggi baris di dalam container flex atau grid, dan tebalnya
tetap 2 px walaupun container meregangkannya.

## Keyboard dan aksesibilitas [#keyboard]

Separator tidak bisa difokus dan tidak punya interaksi keyboard. Screen reader mengenalinya sebagai
pemisah lewat `role="separator"` dan `aria-orientation`. Di mode forced colors (Windows High
Contrast), kedua garis memakai warna sistem sehingga tetap terlihat.

## Kustomisasi [#customization]

Kontrol di stage terbuka; CSS-nya ada di tab `settings.css` setelah warna diganti.

Separator membaca token tema berikut. Pasang di sebuah elemen untuk mengubah separator di dalamnya.

| Token tema | Fungsi |
| --- | --- |
| `--ow-line-dark` | Garis gelap |
| `--ow-line-light` | Garis terang di sebelahnya |

Drawer kode menulis komponen persis seperti yang diatur di stage. Ubah apa pun, dan baris yang
berubah akan menyala.

| Prop | Tipe | Bawaan |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className` | `string \| (state) => string` | |
| `style` | `CSSProperties` | |
| `render` | `ReactElement \| (props, state) => ReactElement` | |

Ref diteruskan ke elemen `div`, dan props lain diteruskan ke Base UI apa adanya.
