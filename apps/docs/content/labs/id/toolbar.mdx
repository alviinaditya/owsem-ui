Toolbar menampung tombol, toggle, link, dan sebuah field dalam satu baris, di atas material panel,
dengan alur terukir di antara grupnya. Toolbar hanya satu perhentian Tab, dan tombol panah
berpindah di dalamnya. Gulir untuk mulai tur; stage mengikuti setiap bagian.

## Tombol dan toggle bersama [#together]

Satu toolbar memuat beberapa jenis item. Tombol bekerja sekali; toggle tetap menyala. Keduanya
tenang: datar dan muted sampai pointer berada di atasnya, dengan ukuran dan spacing Button. Toggle
yang menyala memakai material ditekan, dan tekanan pada keduanya masuk ke 0,97, lalu dilepas
dengan spring settle.

Toggle di toolbar adalah `Toolbar.Button` yang merender Toggle: `render={<Toggle />}`. Toolbar
memberinya tempat dalam urutan tombol panah, Toggle memberinya state menyala, dan tampilan Toggle
yang menang, karena style item toolbar tidak punya specificity.

Stage memutarnya: pointer menyalakan Miring dan Garis bawah, menekan Urungkan, lalu mematikan
keduanya lagi, dan baris di bawah toolbar mengikutinya. Putar scene memutarnya lagi.

## Satu perhentian Tab [#roving]

Sebanyak apa pun itemnya, toolbar hanya satu perhentian dalam urutan Tab, jadi pengguna keyboard
cukup sekali Tab untuk melewatinya. Di dalamnya, tombol panah berpindah antar item dan berputar
di kedua ujung. Tab keluar dari toolbar, dan saat kembali, fokus mendarat di item yang terakhir
dipakai; baris di bawah toolbar menyebut namanya.

Coba sendiri: klik stage, tekan Tab sampai toolbar menerima fokus, lalu pakai tombol panah. Tombol
disabled seperti Ulangi tetap bisa difokus, jadi tetap bisa ditemukan dan diumumkan sebagai tidak
tersedia. Di dalam field, panah menggeser caret dan baru berpindah item di ujungnya, jadi pakai
paling banyak satu field, dan letakkan di akhir.

## Anatomi [#anatomy]

Delapan bagian. Base UI merender role dan fokus berpindah (roving focus); OwsemUI menambahkan class
`ow-toolbar-*`, ukuran, dan ikon. Inspeksi (I) menandai setiap bagian di stage; pilih sebuah nama,
di sini atau di stage, untuk melihat tokennya.

| Bagian | Elemen | Catatan |
| --- | --- | --- |
| <Part name="Root" /> | `div.ow-toolbar` | `role="toolbar"`, `aria-orientation`, dan `data-size`; panelnya |
| <Part name="Group" /> | `div.ow-toolbar-group` | `role="group"`; beri nama dengan `aria-label` |
| <Part name="Toggle" /> | `button.ow-toggle.ow-toolbar-button` | Button dengan `render={<Toggle />}`, jadi punya `aria-pressed` |
| <Part name="Button" /> | `button.ow-toolbar-button` | `data-size`, dan `data-icon-only` bila tanpa label |
| <Part name="Icon" /> | `span.ow-toolbar-icon` | Dekoratif (`aria-hidden`): `startIcon` atau `endIcon`, ukuran font ditambah 2px |
| <Part name="Separator" /> | `div.ow-toolbar-separator` | `role="separator"`, melintang arah toolbar |
| <Part name="Link" /> | `a.ow-toolbar-link` | Tampil seperti tombol; `render` menggantinya dengan link router |
| <Part name="Input" /> | `input.ow-toolbar-input` | Field cekung, setinggi tombol |

## State dan varian [#states]

Stage menampilkan setiap ukuran di kedua tema, masing-masing toolbar dengan toggle yang menyala,
toggle yang mati, sebuah alur, sebuah tombol, dan tombol yang disabled. Pointer menyalakan dan
mematikan Miring di setiap tema.

| State | Tandanya |
| --- | --- |
| Diam | Datar, dengan teks muted |
| Hover | Warna `--ow-hover`, dan teks dengan kontras penuh |
| Sedang ditekan | Mengecil ke 0,97, dengan material ditekan, dalam 90 ms |
| Menyala, untuk toggle | Material ditekan, sama seperti Toggle sendiri |
| Fokus keyboard | Ring 2px dengan jarak 2px, warna `--ow-focus` |
| Disabled | Opacity 45%, tetap bisa difokus |

`orientation="vertical"` menyusun item ke bawah, panah atas dan bawah berpindah antar item, dan
alurnya berbalik melintang. Pilih di kontrol.

## Keyboard dan aksesibilitas [#keyboard]

| Tombol | Aksi |
| --- | --- |
| Tab, Shift+Tab | Masuk dan keluar toolbar, di item yang terakhir dipakai |
| Panah kanan, panah kiri | Item berikutnya atau sebelumnya, berputar di ujung (panah bawah dan atas bila vertikal) |
| Space, Enter | Menekan tombol, atau menyalakan dan mematikan toggle |

Dari kanan ke kiri, panah kiri yang maju. Screen reader mengumumkan toolbar dengan namanya, setiap
grup dengan namanya sendiri, toggle beserta state-nya, dan alur sebagai pemisah.
`loopFocus={false}` menghentikan perputaran di ujung.

Dengan `prefers-reduced-motion`, tekanan mengganti material tanpa mengecil. Di mode forced colors
(Windows High Contrast), toolbar, item, dan field-nya tetap punya tepi 1px berwarna sistem, alurnya
tetap terlihat, dan ring fokusnya `Highlight`.

## Ship it [#ship]

Drawer kode menulis toolbar persis seperti yang diatur di stage. Ganti ukuran, orientasi, atau
warna, dan baris yang berubah akan menyala.

| Bagian | Prop | Tipe | Bawaan |
| --- | --- | --- | --- |
| Root | `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| Root | `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| Root | `loopFocus` | `boolean` | `true` |
| Root, Group | `disabled` | `boolean` | `false` |
| Button, Link, Input | `size` | `"sm" \| "md" \| "lg"` | Milik toolbar |
| Button, Link | `startIcon`, `endIcon` | `ReactNode` | |
| Button, Input | `disabled` | `boolean` | `false` |
| Button, Input | `focusableWhenDisabled` | `boolean` | `true` |
| Semua bagian | `className`, `style`, `render` | | |

`orientation`, `loopFocus`, `disabled`, dan `focusableWhenDisabled` berasal dari Base UI. `size`
pada Input adalah skala teksnya, bukan lebar dalam jumlah karakter: atur `inline-size` sebagai
gantinya. Ref diteruskan ke elemen setiap bagian, dan props lain diteruskan ke Base UI apa adanya.

Impor dari `owsem-ui/base`. Di registry, namanya item `toolbar`; toggle di dalamnya juga perlu
item `toggle`.
